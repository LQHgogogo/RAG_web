========================================
 RAG 智能知识问答系统 - 服务启动命令
========================================

【前提】
1. 确保电脑已安装 Python3
2. 确保已配置环境变量：
   - DEEPSEEK_API_KEY   （大模型，问答用）
   - BAILIAN_API_KEY     （百炼，知识库向量化用）
   （在运行后端的那个终端里配置）

------------------------------------------------
【第一步：启动后端】 端口 8080
------------------------------------------------
在项目根目录 D:\code\PC\RAG_web 下执行：

    python -m uvicorn backend.routes.app_routes:app --host 0.0.0.0 --port 8080

说明：
- 有 --reload 的话改代码会自动重启，但 Windows 上容易崩，建议先不用
- 后端必须从项目根目录启动（用了 backend.xxx 包路径）

------------------------------------------------
【第二步：启动前端】 页面端口 3000
------------------------------------------------
另开一个终端，进入 domain 目录执行：

    cd D:\code\PC\RAG_web\domain
    python -m http.server 3000

------------------------------------------------
【第三步：访问】
------------------------------------------------
浏览器打开： http://localhost:3000

注意：前后端都要启动，页面才能正常工作。

------------------------------------------------
【停止服务】
------------------------------------------------
在对应终端按 Ctrl + C 即可停止。

如果端口被占用、停不掉：
    netstat -ano | findstr :8080     # 查占用 8080 的进程 PID
    taskkill /F /PID <PID>           # 强制结束该进程
